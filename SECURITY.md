# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `support@naturanzafood.com`.
Include the affected URL, reproduction steps, expected impact, and the date/time
of the test. Do not include passwords, tokens, payment screenshots, or customer
data in a report.

Please do not perform denial-of-service tests, social engineering, brute force,
or destructive actions against the production site. A staging environment can be
provided for authenticated or high-impact validation.

## Scope

The production website and its first-party API are in scope. Third-party services,
hosting control panels, and payment providers should be reported to their owners.
